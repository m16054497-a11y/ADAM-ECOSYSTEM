# GameForge AI

Professional starter project for procedural game-level generation, a small PyTorch level Transformer, a Top-2 MoE demo, behavior trees, JSON/OBJ export, FastAPI/CLI entry points, and a Unity importer.

## Download
The complete starter archive is available in this repository as `GameForge_AI_Professional_Starter.zip.b64`. Decode it with:

```bash
base64 -d GameForge_AI_Professional_Starter.zip.b64 > GameForge_AI_Professional_Starter.zip
unzip GameForge_AI_Professional_Starter.zip
```

This is an MVP/starter, not a production-scale autonomous game-generation platform. Tests passed locally (2/2).
